# TM-143 — Text-to-video hybrid ADR retro

## TL;DR

Research-only ADR. Decision: **DEFER** full text-to-video integration; approve a single-vendor **PILOT** spike (Runway Gen-4 Turbo, ≤$50, ≤1 dev-week, behind feature flag). ADR-0022 (image-gen) + ADR-0027 (Lottie loops) already cover the dominant living-entity-motion gap that TM-143 was scoped against, at a fraction of the cost; T2V is 10–500× more expensive per asset than the current edit baseline and would require new sandbox-wrapper + R2 cache + provider-abstraction infra without yet-proven user demand.

## 무엇이 바뀌었나

- New ADR draft: `wiki/01-pm/decisions/PENDING-TM-143-text-to-video.md` (token: `ADR-PENDING-TM-143`).
- Vendor landscape table (May 2026): Runway Gen-4 Turbo / 4.5, Kling 3.0 Standard / Pro, OpenAI Sora 2, Pika 2.2 (fal.ai), Luma Dream Machine — per-second API price, latency, max duration, character-consistency, API openness.
- Two hybrid scenarios analyzed: (a) character-motion-only T2V + Remotion shell, (b) whole-scene T2V. Both blocked on absence of a `<CatalogueClip>` wrapper + R2 cache + sandbox carve-out — scoping work that is not justified pre-evidence.
- Spawn proposal: TM-143-spawn-1 (Runway PILOT spike).
- Code changes: 0. New npm deps: 0 (PILOT, if approved, would add a Runway SDK behind a feature flag — out of scope for this ADR).

## 왜 / 배경

TM-143 was scoped before TM-135 (Remotion best-practices catalogue) and TM-140 (ADR-0027 Lottie motion-loop catalogue) shipped. The original motivation — "we cannot render a recognisable bear walking" — has since been substantially closed by ADR-0022 image-gen + ADR-0027 motion loops. The remaining question is whether a residual cinematic / live-action prompt class still justifies T2V integration; this ADR concludes there is not yet enough evidence to commit, but a cheap PILOT can produce that evidence within ≤$50 and ≤1 dev-week.

## 영향

- **Cost / unit economics:** preserves ADR-0001 baseline (~$0.005/edit, 64% Pro margin). Any T2V at production scale would be 10–500× per asset; deferring keeps the model intact.
- **Sandbox / TM-123 invariant:** no carve-out for `<Video>` / `<OffthreadVideo>` in production. Audio (ADR-0026) and motion-loop (ADR-0027) catalogue wrappers remain the only exceptions.
- **Roadmap:** T2V drops out of this cycle. Re-evaluation gate: PILOT report within 2 sprints, or user-signal-driven re-open.
- **Vendor lock-in risk:** zero new commitments. The vendor field is moving monthly; deferring buys optionality.

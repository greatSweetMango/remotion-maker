# TM-95 — Narrow PR #127 system-prompt clarify rule → living-entity only

## TL;DR

TM-85 bench에서 발견된 data-viz 0% mode_match 회귀를 두 곳에서 동시에 좁힘:

1. **`src/lib/ai/prompts.ts`** — PR #127 `CHARACTER/SCENE/STORY` exception 을 **living-entity only** 로 명시. "narrative scene" 일반 표현 제거. data-viz/motion-graphics 는 항상 즉시 generate 라고 명시.
2. **`src/lib/ai/clarify-gate.ts`** — `COUNT_PATTERNS` 에 data-viz 단위(segments/slices/categories/series/products/devices…) 추가, `DATA_PATTERNS` 에 dashboard 어휘(signups/breakdown/daily/device/category/product…) 추가, `forceSkipClarify` 조건에 `subject AND data` 추가.
3. **`src/lib/ai/generate.ts`** — `forceSkipClarify=true` 인데 entity count 가 없을 때 사용할 새 reinforcement(`FORCE_GENERATE_DATAVIZ_REINFORCEMENT`) 도입. 3차 hardened retry 분기 일반화.

라이브 검증: data-viz 5건 5/5 mode=generate, 평균 latency 33s, 평균 codeLen 2226. 비용 < $0.05 (Haiku 5 calls).

| `src/lib/ai/clarify-gate.ts` | COUNT/DATA 패턴 확장, forceSkipClarify 에 subject+data 케이스 추가, TM-95 dataviz reinforcement 추가. |

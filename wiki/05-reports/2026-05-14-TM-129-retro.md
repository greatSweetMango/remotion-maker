# TM-129 — VISUAL-ONLY POLICY 갱신: Audio catalogue allow rule

## TL;DR

`GENERATION_SYSTEM_PROMPT`의 TM-123 블랭킷 deny ("NEVER emit `<Audio>`")를 ADR-0026 §3에 맞춘 catalogue allow rule로 교체. Video / OffthreadVideo / IFrame은 그대로 deny. `<Audio src={staticFile('audio/<slug>.mp3')} />` 리터럴 shape만 허용임을 명시하고, TM-127의 5 mood (chill / upbeat / cinematic / lofi / electronic)와 TM-130 picker용 `bgmTrack` PARAMS 컨벤션을 추가.

## 무엇이 바뀌었나

- `src/lib/ai/prompts.ts` (~50 LOC) — `VISUAL-ONLY POLICY` 블록 전면 개정:
  - "NEVER emit `<Audio>`" 문구 제거 (TM-128 sandbox allow-list 가용)
  - "DO NOT use `<Video>` / `<OffthreadVideo>` / `<IFrame>`" 명시 유지
  - 허용되는 유일한 Audio shape를 리터럴 예시로 제공
  - `staticFile(PARAMS.bgmTrack)` 같은 변수 인자가 REJECTED 됨을 경고 (모델이 "도와주려고" runtime 변수로 wire 하려는 실수 방지)
  - TM-127 `AUDIO_MOODS` 5종 + 슬러그 명명 컨벤션 (예: `audio/chill-sunrise.mp3`)
  - TM-130 picker용 PARAMS 패턴 (`// type: bgmTrack` + `bgmVolume`)
  - Audio는 OPTIONAL — 시각적 요청에는 강제 주입 금지, 기존 시각 cue (pulses, equalizer bars, Math.sin) fallback 유지
- `__tests__/lib/ai/prompts-audio-policy.test.ts` (new, 8 cases) — 가드 테스트:
  - Video / OffthreadVideo / IFrame deny 유지 회귀
  - TM-123 "NEVER emit <Audio>" 문구 부재 확인
  - 리터럴 staticFile shape 명시 확인
  - 변수 src 경고 명시 확인
  - 모든 `AUDIO_MOODS` (manifest.ts에서 import) verbatim 포함 확인
  - `bgmTrack` + `// type: bgmTrack` 컨벤션 확인
  - Audio OPTIONAL + 시각 cue fallback 보존 확인
  - `GENERATION_WITH_CLARIFY_SYSTEM_PROMPT`도 동일 룰 상속

## 왜 / 배경

ADR-0026 §3 (TM-126)에서 TM-123 블랭킷 deny를 catalogue 기반 allow로 전환하기로 결정. TM-127 (manifest), TM-128 (sandbox structural allow-list), TM-130 (picker UI), TM-131 (Lambda export) 모두 인프라 측에서 audio를 다시 활성화했으나 — generation prompt가 여전히 "NEVER emit Audio"를 가르치면 모델이 BGM 요청에도 시각 메타포만 생성한다. TM-129가 이 마지막 인지 격차를 해소.

## 영향

- **AI**: 모델이 BGM이 적절한 프롬프트(예: "chill lo-fi countdown video with background music")에 대해 catalogue 트랙을 emit 가능. 시각 전용 요청에는 audio 미주입 (OPTIONAL 명시).
- **Sandbox 안전**: 인프라 변경 0. 모델이 invalid shape (변수 src, template, external URL)를 emit해도 TM-128 allow-list가 차단. Prompt-level guidance가 first-line, sandbox는 load-bearing.
- **Cache (ADR-0003)**: `GENERATION_SYSTEM_PROMPT` 본문이 변경되어 `cache_control: ephemeral` 캐시 키가 무효화됨. **다음 N 건의 edit/generation 요청은 cache miss 발생 — 입력 토큰 비용 일시 증가**. 정상 동작; 새 prompt가 stable해지면 24h 내 캐시 hit rate 회복.
- **테스트**: 8 new tests pass. 회귀 영향 없음 (TM-71 카테고리 가드 테스트, TM-128 sandbox 56/56 모두 그린).

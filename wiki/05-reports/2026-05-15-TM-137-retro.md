# TM-137 — CHARACTER/SCENE 가이드라인 추가

## TL;DR

TM-135 RCA의 P0 D2 권고를 구현. `GENERATION_SYSTEM_PROMPT`의 `CATEGORY-SPECIFIC GUIDELINES` 블록에 **`[CHARACTER / SCENE / NARRATIVE]`** 섹션 (~60줄) 신규 추가. 살아있는-개체 프롬프트가 단일 평면 위 단일 도형(곰돌이→갈색 원)으로 collapse되는 회귀를 방지하기 위해 다음을 강제:

- **3-layer scene depth** (foreground / midground / background, parallax 다른 속도)
- **분리된 사지** (head + body + ≥2 limbs + face features), SVG `<g transform>` 그룹
- **walk-cycle keyframes** (`Math.sin` anti-phase legs + body bob)
- **motion arc** (translateX-only 금지, 보조 motion 필수)
- **palette ≥3색** + 톤 hint 모든 layer 적용
- **rule of thirds** composition (캐릭터 1/4–1/3 frame)
- **asset-gen 핸드오프** — `imageUrl` PARAMS 있으면 `<Img src>` 우선
- **Anti-patterns 6종 명시** (single circle / flat scene / translateX-only / monochrome / oversize / no limbs)

코드 inline sketch(walk pattern SVG/JS)도 시스템 프롬프트에 직접 포함.

## ADR 영향

**ADR-0003 (Prompt caching on edit)** — 시스템 프롬프트 변경은 cache key 무효화. 캐시 ephemeral은 system 프롬프트 전체를 한 청크로 처리하므로 신규 prompt가 한 번 fed되면 동일 system 프롬프트 전체가 다시 캐시됨. 첫 요청만 cache miss($0.00125/M token 소폭 증가), 이후 적중률 회복. 별도 ADR 필요 없음.

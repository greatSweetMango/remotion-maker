# TM-140 — Lottie catalogue scaffold (ADR-0027)

## TL;DR

ADR-0027을 신설하고 Lottie 카탈로그 1차 스캐폴드(랩퍼/매니페스트/로더/샌드박스 deny + 플레이스홀더 자산)를 랜딩. ADR-0026 audio policy 패턴을 1:1 미러. 신규 dep `@remotion/lottie` + `lottie-web` 추가(Remotion 공식, 사용자 승인). 큐레이션·프롬프트·UI는 4개 후속 task로 분리.

## 무엇이 바뀌었나

- **ADR-0027** 신설 — `wiki/01-pm/decisions/0027-lottie-catalogue.md` + README 인덱스 갱신.
- **Deps**: `@remotion/lottie@^4.0.448`, `lottie-web` 추가 (Remotion 공식 패키지, ADR-0026 패턴 ROI 인정 — 사용자 사전 승인).
- **랩퍼 컴포넌트**: `src/remotion/CatalogueLottie.tsx` — `asset` prop 검증 → `staticFile("lottie/<slug>.json")` fetch (`delayRender`/`continueRender` Remotion 권고 패턴) → `<Lottie>` 렌더. invalid asset → `null` (TM-123 cascade 차단).
- **Manifest split (TM-133 lesson)**:
  - `src/lib/lottie/manifest-types.ts` — client-safe 타입 + regex + `isValidCatalogueLottieAsset`.
  - `src/lib/lottie/manifest-loader.ts` — `'server-only'` + `node:fs/promises` + sha256 integrity check.
  - `src/lib/lottie/manifest.ts` — client-safe 배럴 (loader 재export 금지).
- **Sandbox deny**: bare `<\s*Lottie\b` → reject (`<CatalogueLottie`는 정규식이 매칭하지 않으므로 자연 통과 — ADR-0026 §B와 동일 메커니즘).
- **Evaluator scope**: `CatalogueLottie`를 `CatalogueAudio`와 나란히 globals로 주입 (`src/lib/remotion/evaluator.ts`).
- **Placeholder 자산**: `public/lottie/MANIFEST.json` v1 + `public/lottie/bear-walk.json` (60f bobbing circle, sha256-stamped). 후속 큐레이션 전까지 dev/test 통과용.

## 왜 / 배경

TM-135 RCA에서 "곰돌이 → 갈색 원" regression의 구조적 capability gap이 드러났다. ADR-0022가 image-gen으로 정적 자산은 해결했지만 **walk-cycle / idle-loop / dance-loop 같은 living-entity motion**은 여전히 Ken-Burns 팬으로만 표현됨. LottieFiles에 무료(CC0/MIT) walk-cycle 자산이 풍부하고, Remotion 공식 `@remotion/lottie`가 deterministic seek를 지원하므로, ADR-0026 audio catalogue와 동일한 패턴(curated `staticFile` + 랩퍼 + sandbox deny + PARAMS isolation)으로 도입.

## 후속 작업 (spawn 제안)

본 task는 **scaffold + policy** 까지. 카탈로그 큐레이션·프롬프트·UI·Lambda 검증은 4개 follow-up:

1. **TM-140-spawn-1** — LottieFiles에서 5–10건 living-entity 자산 큐레이션 (CC0/MIT only), MANIFEST.json 갱신, visual smoke test로 expression-heavy 파일 제외. (curation; non-engineering blocking)
2. **TM-140-spawn-2** — `src/lib/ai/prompts.ts` audio-policy 블록 옆에 Lottie catalogue enum + emission rule (`<CatalogueLottie asset={lottieAsset} ...>`) 추가. ADR-0022 image-gen은 비-카탈로그 fallback로 유지.
3. **TM-140-spawn-3** — Customize-tab Lottie picker (TM-130 audio picker 재사용 패턴, in-place preview).
4. **TM-140-spawn-4** — Remotion Lambda render verify smoke test (`public/lottie/` 번들 포함 확인 + 5s composition 출력 검증).

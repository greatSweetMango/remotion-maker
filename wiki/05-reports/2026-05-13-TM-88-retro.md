# TM-88 회고 — PARAMS `type:image` regen-prompt UI

ADR-0022 1차 follow-up. TM-84 spike에서 검증된 `gpt-image-1` 자산 생성을 Customize 탭의 사용자 인터랙션으로 확장.

## 한 줄 요약

`type:image` PARAMS 옆에 **"Regenerate with AI"** 버튼이 노출되어, 사용자가 프롬프트를 즉석에서 편집하고 새 이미지를 받아 `paramValues`에 그대로 꽂힌다. PRO 한정·$0.04/call·1024² 단일 호출.

## 변경 사항

### 1. `extract-params.ts` — `regen_prompt:` 어노테이션 파싱
- PARAMS 라인 코멘트에서 `regen_prompt: "..."` (single/double/backtick quote 모두) 추출 → `Parameter.regenPrompt: string | undefined`.
- 콤마 포함 프롬프트 지원 — 따옴표 안 콤마는 grammar 충돌 없음 (regex가 quoted run을 우선 매치).
- 미제공 시 `regenPrompt`는 `undefined` (기존 backward-compat 유지).

### 2. `POST /api/asset/regen-image` (신규 라우트)
- Auth 필수 → `validatePrompt` (TM-58, 2000자 cap) → PRO tier 검사 → `OPENAI_API_KEY` 검사 → `generateAssetImage(prompt)` 호출.
- Response: `{ paramKey, imageUrl: <dataUrl>, costUsd, latencyMs, size, quality, prompt, pricePerImageUsd }`.
- 오류 매핑:
  - 401 unauthed / 400 bad input / 403 free-tier (`upgradeRequired: true`)
  - 404 user missing / 503 OPENAI_API_KEY missing
  - 422 + `CONTENT_POLICY` (OpenAI moderation reject — 실존인물 등)
  - 502 + `IMAGE_GEN_FAILED` (기타 업스트림 실패)

### 3. `ParameterControl.tsx` — UI 추가
- `type:image` 파라미터 위에 **썸네일 미리보기** (`<img>` 직접; data URL 호환 위해 `next/image` 의도적 회피, eslint-disable 인라인 설명).
- `regenPrompt`가 있는 image 파라미터에만 **Regenerate with AI** 버튼 노출 — seed prompt 없는 케이스(업로드 자산)는 비활성으로 두어 UX 혼선 차단.
- Dialog (shadcn `Dialog`) → Textarea(prompt) + Cancel/Regenerate 버튼. Loading 상태 + 마지막 호출 비용/latency 미니 라인. 추가 npm dep 0개.
- `useEffect`로 seed reset 안 함 → `onOpenChange` 콜백에서 setState (lint rule `react-hooks/set-state-in-effect` 회피).

### 4. 테스트 추가
- `__tests__/lib/extract-params.test.ts`: regen_prompt 어노테이션 4 케이스 (double/single quote, 콤마 포함, 미제공 backward-compat).
- `__tests__/api/asset/regen-image/route.test.ts`: 11 케이스 — auth/validation/tier/key/happy/content_policy/generic_error.
- 총 20 new tests, 0 regression (lib + asset api total 550 pass).

## 결정 / 트레이드오프

- **regen 노출 조건 = `regenPrompt` 존재**: LLM이 명시한 시드 프롬프트가 없으면 버튼을 숨겨, 사용자가 빈 상자에서 시작하는 혼선을 차단. 업로드 자산은 종전대로 ResourcePanel에서 교체.
- **응답 = data URL만**: R2 영속화는 별도 follow-up. 현 시점 data URL이 그대로 PARAMS에 들어가도 Remotion `<Img>` 호환. ADR-0022 §"Caching"은 후속 task에서 다룬다.
- **spend ledger 미통합**: `recordUsage`는 토큰 기반 가격만 처리 — flat-rate image-gen은 응답의 `costUsd`로 클라이언트에 노출하는 정도. 별도 task로 ledger 확장 권장.

## Goal
Asset management v2: per-asset tags, single-folder organization, and bulk-select
actions on the dashboard.

## Decisions
- **Storage**: Prisma+SQLite has no scalar list. `Asset.tags` is a JSON-encoded
  string column (default `"[]"`). All read/write goes through
  `src/lib/asset/tags.ts` so the encoding lives in one place. Folder is a
  single nullable string (`Asset.folder`) — flat namespace for MVP, "/"-nesting
  can be added later without schema change. Validation rejects "/" and control
  chars in folder names so future nesting is forward-compatible.
- **Bulk semantics**: owner-scoped, soft-deleted rows excluded (except for the
  `soft-delete` action which is idempotent). Tag-add/remove/set are
  per-row read-modify-write but skip rows whose tag set wouldn't change so
  `updatedAt` doesn't churn and reorder the dashboard list. `MAX_IDS=200`
  per request.
- **Tag filter on list endpoint**: AND semantics across repeated `?tag=` query
  params, implemented as substring match on the JSON-encoded column
  (`tags: { contains: "\"foo\"" }`). Safe because `JSON.stringify` always
  quotes entries — no false positives across tag boundaries.
- **Facets**: GET /api/assets and the dashboard SSR both compute `{ folders,
  tags }` facets unscoped to the current filter so chip lists don't disappear
  as the user filters.

## Schema (Prisma db push, no migration files convention here)
```
Asset.tags    String   @default("[]")  // JSON array
Asset.folder  String?
@@index([userId, folder])
```

## API
- `PUT  /api/asset/[id]/tags` — replace tag set (array of strings).
- `GET  /api/asset/[id]/tags` — convenience read (decoded array).
- `PATCH /api/asset/[id]/folder` — set/clear folder (string|null).
- `POST /api/assets/bulk` — `{ ids[], action: tag-add|tag-remove|tag-set|folder-move|soft-delete }`.
- `GET  /api/assets` extended with `?tag=` (repeatable, AND) and
  `?folder=<name>|__root__`. Response now includes `facets.{folders, tags}`
  and decoded `tags: string[]` on each row.

## UI
- AssetCard: tag chips (max 5 + overflow), folder badge, "Edit tags" /
  "Move to folder" menu items, chip-style tag editor (Enter/comma to add,
  Backspace to delete last, X per chip).
- AssetGrid: facet chip rows (folders + top tags), "Select" button toggles
  bulk-select mode. Toolbar exposes Select-all-on-page, Add tags, Move to
  folder, Move to Trash (with confirm).

# TM-118 — spend-ledger.jsonl monthly rotation policy

## 배경

TM-101 이 `.agent-state/spend-ledger.jsonl` 스키마를 정의하고 TM-112 가 PostToolUse hook 에서 매 LLM call 마다 한 줄 append 하기 시작했다. 이 파일은 append-only 라 무한 성장하며 stop-guard 의 cost_burst 검사 / dashboard roll-up 등 hot-path 리더가 점차 느려진다. 월간 회전 정책을 도입한다.

## 구현

| 컴포넌트 | 위치 | 역할 |
|---|---|---|
| 회전 스크립트 | `scripts/orchestrator/rotate-spend-ledger.mjs` | ledger 를 `ts` 기반 월별로 그룹핑 → 지난 달 데이터를 gzip 압축하여 archive 에 append → 원본은 현재 달만 남기고 atomic rewrite |
| 단위 테스트 | `scripts/tests/test-rotate-spend-ledger.sh` | 7 케이스 (mixed-month, missing, all-current, idempotent, malformed, multi-month, dry-run) → 28 assertions pass |
| launchd plist | `scripts/launchd/com.easymake.spend-ledger-rotate-monthly.plist` | 매월 1일 00:05 (로컬) 트리거 |
| 상태 파일 | `.agent-state/spend-ledger.rotate.json` | `{ last_rotated_at, archived_months: { "YYYY-MM": "complete" } }` |

### 설계 포인트

- **신규 dep 0** — `node:zlib` `gzipSync` 만으로 충분. gzip member 연결은 RFC 1952 §2.2 에 따라 `zcat` 이 정상 디코드.
- **flock 패턴 (TM-96)** — `.agent-state/.spend-ledger.lock` 을 `post-tool-use.sh` 와 공유. 회전 중 writer hook 과 race 없음. flock 미지원 시 O_EXCL sentinel 폴백.
- **Idempotent** — 같은 달 재실행 시 rotate-state 에 `complete` 마커가 있고 archive 파일이 존재하면 append 스킵. 두 번째 실행은 `noop / no_old_rows`.
- **Malformed-safe** — JSON parse 실패하거나 ts 가 없는 라인은 live ledger 에 남기고 `malformed` 카운터로 노출. 운영자가 직접 확인.
- **Atomic rewrite** — tmp file + `rename()` 로 부분 쓰기 방지.
- **cutoff override** — `--cutoff-month=YYYY-MM` 로 수동 회전 가능 (대응 테스트는 고정 cutoff `2026-05` 사용).
- **stdout 분리** — telemetry 는 stderr, `--json` 결과 라인만 stdout → 파이프 조합 안전.

## 운영

```bash
# 수동 dry-run
node scripts/orchestrator/rotate-spend-ledger.mjs --dry-run --json

# 등록 (사용자 머신, README.md §1-2 참조)
launchctl load -w ~/Library/LaunchAgents/com.easymake.spend-ledger-rotate-monthly.plist
```

회전 후 시간대 분석은 archive + 현재 ledger 를 함께 스트림:

```bash
zcat .agent-state/spend-ledger.archive.*.jsonl.gz; cat .agent-state/spend-ledger.jsonl
```

# TM-191 — deny-list 'global' 오탐 수정 (주석/문자열 strip)

## 한 줄 요약

`FORBIDDEN_PATTERNS` 스캔을 **주석·문자열 내용을 blank 처리한 code-only view**에 대해 수행하도록 정밀화해, PARAMS 주석 `// ... sequence: global` 이 `Forbidden: global` 을 오탐시켜 DataStory/HighlightReel/ProductIntro 3개 템플릿이 reject되던 회귀를 수정. 실제 `global` 객체 접근은 여전히 차단(보안 무변).

## 원인 (RCA)

- `src/lib/remotion/sandbox.ts:68` (및 plugin mirror `validate.ts:157`)
  `{ pattern: /\bglobal\b(?!\s*[A-Za-z0-9_])/, label: 'Forbidden: global' }`
- 패턴이 **소스 텍스트 전체**(주석/문자열 포함)에 대해 `.test()` 되어, PARAMS 어노테이션 주석 `// type: color, sequence: global` 의 단어 `global` 을 금지토큰으로 매칭.
- 영향: 표준 35 템플릿 중 `sequence: global` 어노테이션을 가진 DataStory / HighlightReel / ProductIntro 3개가 `validateRemotionCode` 에서 false-positive reject (TM-182 작업 중 발견).

## 수정 (최소 침습, rebase-friendly)

- DENY_LIST 자료구조는 **변경하지 않음** (TM-184 충돌 회피). 매칭 입력만 정밀화.
- `stripCommentsAndStrings(code)` 헬퍼 신설 — 단일 선형 스캔(백트래킹 없음, DoS-safe):
  - 라인주석 `//…`, 블록주석 `/*…*/` 내용 제거
  - 문자열/템플릿 리터럴 **델리미터는 유지하고 내용만 blank** (구조/라인 정렬 보존; allow-list shape 체크는 raw `code` 사용 유지)
- `validateCode` / `validateRemotionCode` 의 `FORBIDDEN_PATTERNS` 스캔 + `detectRecursivePromiseChain` 입력을 `stripCommentsAndStrings(code)` 결과(`scanCode`)로 교체.
- 두 파일(`src/lib/remotion/sandbox.ts`, `plugin/remotion-eval/src/validate.ts`)에 **동일 헬퍼 미러** (TM-115 sync 유지).
- 부수: denylist-sync 가 **base 시점부터 이미 깨져 있던** `<Lottie>`(ADR-0027) 미러 누락을 발견 → plugin에 1줄 미러 추가해 sync 복구.

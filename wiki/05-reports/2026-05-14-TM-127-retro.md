# TM-127 — Audio catalogue manifest + stub fixtures (ADR-0026 §1)

## 한 줄 요약

ADR-0026 §1 이 정의한 `public/audio/` 큐레이션 카탈로그의 **schema/loader/검증 파이프라인**을
fixture audio (ffmpeg 사인파 stub × 15) 위에 먼저 착륙시켰다. 후속 task(sandbox allow-list,
prompt enum, customize UI, Lambda smoke)는 이제 안정적인 `MANIFEST.json` 위에서 진행 가능.

## 결정 배경 — 사용자 명시 승인

이 PR 은 **fixture 전용**. 실제 royalty-free 큐레이션은 별도 task 로 분리하기로 사용자가
승인. 이유: schema/validator/integrity-check 가 카탈로그 내용물보다 먼저 stable 해야
TM-126-spawn-{2,3,4,5} 가 병렬 진행 가능.

## 한 일

1. **`public/audio/MANIFEST.json` (v1)** — 5 mood × 3 track = 15 entry. Schema:
   `{ filename, mood, bpm, durationSec, license, attribution, sha256, bytes }`.
2. **`scripts/audio/generate-stub-tracks.sh`** — ffmpeg `sine=...` 로 stub mp3 생성 +
   sha256 계산 + manifest 재작성. 실제 큐레이션 시 이 스크립트의 `TRACKS=()` 만 갈아끼우면 됨.
3. **`src/lib/audio/manifest.ts`** — plain TS validator (zod 도입 X). API:
   `parseAudioManifest`, `loadAudioManifest`, `hashAudioAsset`, `verifyAudioCatalogueIntegrity`,
   `AudioManifestError`. Mood 는 closed enum (`AUDIO_MOODS`). filename 정규식
   `^[a-z0-9-]+\.mp3$` — ADR-0026 §B-2 의 sandbox regex 와 정확히 동기.
4. **`__tests__/lib/audio-manifest.test.ts`** — 13 케이스 (parser negative + fixture
   integrity + sha256 매치). 모두 green.

## 검증

- `npx jest __tests__/lib/audio-manifest.test.ts` → **13/13 passed**.
- `npx eslint src/lib/audio __tests__/lib/audio-manifest.test.ts` → clean.
- `npx tsc --noEmit` → 신규 파일 0 error (기존 pre-existing 에러는 본 PR 무관, 타 task 에서 처리).

## 주의 — fixture 한계

- mp3 들은 192kbps 사인파라 **들으면 째질 수 있다**. 사용자 노출 전에 큐레이션 task 필수.
- `note` 필드에 stub 임을 명시: `"TM-127 stub catalogue. ffmpeg-generated sine tones; replace with curated CC0/MIT-0 tracks before launch."`
- license 는 전부 `CC0-1.0` 으로 표기 (사인파는 저작권 대상 X) — 큐레이션 시 실제 라이선스로 갱신.

## 후속 task

ADR-0026 §Decision 의 spawn list 그대로:

- TM-126-spawn-2 sandbox `<Audio>` allow-list (regex/AST)
- TM-126-spawn-3 prompt enum 주입 (filename 리스트)
- TM-126-spawn-4 customize UI BGM picker
- TM-126-spawn-5 Lambda 번들 smoke
- (별도) **실제 큐레이션 task** — 본 PR 스크립트로 자리잡은 entry 들을 진짜 트랙으로 교체

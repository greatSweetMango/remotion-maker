# TM-130 — Customize UI: BGM track picker + in-place play preview

## TL;DR

`bgmTrack` PARAMS (e.g. `bgmTrack: "audio/chill-sunrise.mp3"`) now renders a
mood-grouped Select + play/pause button in the Customize panel. The picker
fetches `/api/audio/manifest`, swaps tracks as a pure PARAMS mutation
(ADR-0023 boundary preserved — no LLM edit), and previews via the browser's
native `HTMLAudioElement` (zero new deps).

## 무엇이 바뀌었나

- `src/types/index.ts` — added `'bgmTrack'` to `ParameterType`.
- `src/lib/ai/extract-params.ts` — recognizes
  - explicit `// type: bgmTrack` annotation, and
  - auto-detects unannotated `bgmTrack` / `*Track` keys whose value matches
    the catalogue regex `audio/<name>.mp3` (mirrors ADR-0026 §B.2 sandbox
    allow-list). Group → `media`.
- `src/app/api/audio/manifest/route.ts` (new) — `GET /api/audio/manifest`
  serves the curated catalogue (sha256 stripped). `force-static` +
  `s-maxage=3600` cache.
- `src/components/studio/ParameterControl.tsx` — new `BgmTrackControl` with
  shadcn `Select` (mood-grouped: chill / upbeat / cinematic / lofi /
  electronic) and a `Play`/`Pause` button bound to a single shared
  `HTMLAudioElement` (lazy `preload=none`, paused on unmount + on track
  swap).
- Tests: 5 new `extract-params` cases (annotation + auto-detect happy paths,
  plus negative tests for non-catalogue values and non-Track keys), and a
  smoke test for the manifest route.

## 왜 / 배경

ADR-0026 (TM-126) re-introduced audio via a curated `staticFile` catalogue
after TM-123 had blanket-denied `<Audio>`. §4 requires the Customize panel
to swap tracks **without an LLM edit** (ADR-0023 — track swap is a pure
PARAMS change). TM-127 already shipped the manifest loader; TM-130 closes
the loop on the user-facing picker.

## 영향

- **Code**: +1 API route, +1 control component, ~30 LOC in extract-params.
  No dep changes.
- **Sandbox / safety**: picker only emits values present in the manifest
  (or, if the LLM emitted an out-of-catalogue path, the auto-detect
  regex rejects it before the control is offered). The sandbox AST check
  on `<Audio src={staticFile("audio/…")}>` remains the load-bearing
  invariant — the picker is UX, not security.
- **UX**: users can hear before committing; mood grouping makes the
  catalogue scannable without reading filenames.
- **Edit ≠ Render** (ADR-0001): preview uses `/audio/<name>.mp3` static
  asset, no server render involved.
